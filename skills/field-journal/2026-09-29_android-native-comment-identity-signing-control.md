# Android 旧客户端评论目标与重签启动对照的匿名经验记录

状态：修复任务完成；记录可复用方法与验证边界。

## 场景

一个旧 Android 视频客户端出现图文动态有评论数却没有正文，另有部分竖屏视频在全屏切换时页面关闭。修复任务在已授权的实体手机上进行，原始样本和旧候选保留。

## 可复用发现

可见评论数不等于有效评论目标。旧格式卡片解析失败时，评论分支可能带入无效业务 ID，而同一次原生动态扩展里仍有可用的业务身份。应先确认内容身份匹配、业务 ID 为正且类型对应已有客户端语义，再复用原生评论组件；明确的服务器评论 URI 应保持优先。未知、冲突、跨内容或溢出输入不可强行补全。

网页回退会引入额外故障。移动网页可能重定向，HTTP200也不保证包含预期声明元数据。记录响应状态与有限结构信息，但优先使用已经接收的原生业务字段。

业务补丁之后的启动故障需要不改业务代码的签名对照。匹配原始签名格式的对照有助于缩小容器/初始化假设；它不能单独证明某个原生库是首要原因。短时停在首次提示的进程存活也不能当成推荐首页启动通过。

## 验证与边界

最终构建的两项给定样例经用户真机验收，并关联到正确内容与评论业务目标。解析/类型上下文回归、原始类保留、签名/对齐和安装哈希分别记录。修复验收只覆盖该构建、该手机和给定样例；原始失败编码和历史原生错误首个调用者仍 UNKNOWN。

本记录不包含真实域名、内容 ID、账号、手机序列号、本机路径、签名密钥、原始 APK 或原始手机日志。
