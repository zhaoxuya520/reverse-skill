# reverse-skill 快速开始与社区问题说明

## 项目定位

`reverse-skill` 是给 AI 客户端读取的逆向工程 / 安全研究技能、规则和工具文档集合，不是一个单独的可执行应用。使用前先确认你对分析目标拥有明确授权，或正在使用合法的 CTF、教学或测试环境。

## 基本用法

先下载仓库：

    git clone https://github.com/zhaoxuya520/reverse-skill.git
    cd reverse-skill

再把项目目录交给你使用的 AI 客户端作为工作区或文档来源。核心文件包括：

- `RULES.md`：一般规则与安全边界。
- `skills/MASTER-ROUTING.md`：技能路由与任务分流。
- `skills/*/SKILL.md`：各专业领域的技能说明。
- `docs/platforms/`：不同操作系统的工具安装说明。

本项目保持客户端中立。OpenCode、Codex、Cursor、Claude Code 等客户端的实际加载方式以各客户端官方文档为准；不要假设某一个客户端的 plugin 或同步格式能套到其他客户端。

## OpenCode、Codex 与同步问题

若客户端显示 `Not Synchronizable` 或无法同步，先确认工作区是否指向完整的仓库根目录、文件权限是否允许读取，以及客户端是否支持该目录格式。最可靠的替代方式是直接在本地工作区打开仓库，并在对话中明确引用所需的规则或技能文件。若问题仍可复现，回报时请附上客户端版本、操作系统、完整错误信息与最小复现步骤。

## AI 拒绝处理分析请求

AI 的安全策略不会因为提示里写了「我已授权」就必然允许所有操作。请只处理合法授权的目标，避免要求未授权入侵、凭证窃取、持久化或破坏性操作；可将请求限定为代码理解、样本分析、漏洞修补、CTF 或防御性验证。对于特定 APK、网站或账户，请先准备可验证的授权范围与测试环境。

## Python 工具与 uv

独立命令行工具可以使用：

    uv tool install PACKAGE_NAME

项目依赖则使用隔离环境：

    uv venv
    uv pip install -r requirements.txt

不要机械地把所有 `pip` 字符串替换成 `uv pip`；`python -m pip`、`pipx` bootstrap 与已有虚拟环境各有用途。仓库 bootstrap 仍以 `bootstrap-manifest.json` 为准，当前默认隔离通道是 `pipx`，不是全量改成 uv。若尚未安装 `uv`，请用操作系统包管理器或明确建立的虚拟环境，不要把安全工具直接装到系统全局 Python。

## ZIP 报毒与下载安全

逆向工程工具可能包含二进制、调试器、封装文件或测试数据，容易触发杀毒软件的启发式检测。杀毒警告既不证明安全，也不证明恶意。请勿停用杀毒软件或盲目略过警告。

打开压缩包前，请从预期的 HTTPS 仓库或 release 页面下载，核对 checksum 或 release digest（若有），检查压缩包内容，并用最新的安全软件扫描。不要因为文件能下载成功，就直接执行其中未知的二进制、脚本或安装程序。

## 账户、贡献与未具体化回报

请遵守 AI 客户端、GitHub、工具供应商及目标环境的服务条款。仓库本身无法保证第三方平台不会限制账户，也不能替平台决定账户政策。若要贡献 radare2 或其他技能，请先阅读 `skills/CONTRIBUTING.md`，并以小型、可验证的 Pull Request 提交。

只有包含完整错误信息、环境信息与复现步骤的问题，才适合进一步修复。像只有「病毒」「gaha」或「test」的回报，请补充文件名、下载 URL、扫描产品、版本与复现方式。
